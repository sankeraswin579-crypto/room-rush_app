# Room Rush 1.0.3

- **AI Practice Bot (RushBot)**: Play and practice solo or fill empty spots with an intelligent AI bot.
- **Tactical Lifelines**: Added 50:50 (eliminate two wrong choices) and Double Down (2x points risk/reward).
- **Live Floating Reactions**: Real-time animated emoji dock (🔥, 👏, 😂, 🧠, 💀, 🎯) for interactive multiplayer banter.
- **Expanded Trivia Bank**: Comprehensive question collection across Science, Geography, Nature, Pop Culture, and Tech with category filtering.
- **Procedural Synthesizer Audio**: In-game audio cues powered by the Web Audio API for timer ticks, streaks, and victory fanfare.
- **Dynamic Neon Timer**: Visual urgency timer bar shifting through multi-stage warning colors.
- **Clean Repository Tracking**: Portable build binaries safely excluded from git history.
